# afisha — решения и ловушки

Наследует `tools/editor-design.md` проекта entropic division (v1–v3, «стол и лист»); здесь — то, что появилось при
выделении редактора в самостоятельный продукт. План: `~/.claude/plans/majestic-knitting-horizon.md` (30.09.2026).

## Шаг 1 (01.10.2026): walking skeleton

- **Раскладка**: `afisha.py <сайт>` → `server/app.py`; редактор отдаётся по `/_editor/`, сайт — от корня, поэтому
  все адреса страниц в клиенте абсолютные (`/index.html`, `/${pg}.html`). `_afisha/` не отдаётся никогда;
  `src/` отдаётся (модалка обрезки берёт исходник вырезки оттуда), но не публикуется.
- **Файлы только utf-8 + LF** через `Site.read/write` — иначе на Windows кириллица и CRLF ломают страницы и push.
- **Порт**: `SO_REUSEADDR` включён только не на Windows (там он пускает второй сервер на занятый порт); на POSIX
  без него после остановки сервера порт минуту держится TIME_WAIT и «занят».
- **Единственное отклонение от старого поведения**: `zoomFit()` считает масштаб по `offsetWidth/Height` стола, а не
  `client*` — иначе при видимых полосах прокрутки вписывание выходит с лишним запасом (t15 «Ctrl+1»).
- **Тесты**: `tests/run.py` поднимает сервер на свежей копии фикстуры **для каждого харнесса** (t11 в конце меняет
  ширину афиши, t15 ждёт 1400). Профиль Firefox без `prefersReducedMotion` (анимации `fx-*` проверяются), с ним —
  только для скриншотов. Фикстура `tests/fixture-forest` = site2 после `migrate()` при 1400 (сделано старым
  редактором, харнесс `mkfix`); из t11 удалены 5 утверждений про migrate, остальные — только пути.
- **Ловушка оболочки**: `pkill -f 'serve.py 8791'` убивает сам вызывающий shell (его командная строка содержит тот
  же текст). Сервер в скриптах убивать по PID.
- **Вырезки** пока не перенесены (`process_cutout` отвечает ApiError) — шаг 2.
