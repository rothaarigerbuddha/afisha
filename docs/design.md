# afisha — решения и ловушки

Наследует `tools/editor-design.md` проекта entropic division (v1–v3, «стол и лист»); здесь — то, что появилось при
выделении редактора в самостоятельный продукт. План: `~/.claude/plans/majestic-knitting-horizon.md` (30.09.2026).

## Шаг 1 (01.10.2026): walking skeleton

- **Раскладка**: `afisha.py <сайт>` → `server/app.py`; редактор отдаётся по `/_editor/`, сайт — от корня, поэтому
  все адреса страниц в клиенте абсолютные (`/index.html`, `/${pg}.html`). `_afisha/` не отдаётся никогда;
  `src/` отдаётся (модалка обрезки берёт исходник вырезки оттуда), но не публикуется.
- **Файлы только utf-8 + LF** через `Site.read/write` — иначе на Windows кириллица и CRLF ломают страницы и push.
- **Порт**: `SO_REUSEADDR` включён только не на Windows (там он пускает второй сервер на занятый порт); на POSIX
  без него после остановки сервера порт минуту держится TIME_WAIT и «занят».
- **Единственное отклонение от старого поведения**: `zoomFit()` считает масштаб по `offsetWidth/Height` стола, а не
  `client*` — иначе при видимых полосах прокрутки вписывание выходит с лишним запасом (t15 «Ctrl+1»).
- **Тесты**: `tests/run.py` поднимает сервер на свежей копии фикстуры **для каждого харнесса** (t11 в конце меняет
  ширину афиши, t15 ждёт 1400). Профиль Firefox без `prefersReducedMotion` (анимации `fx-*` проверяются), с ним —
  только для скриншотов. Фикстура `tests/fixture-forest` = site2 после `migrate()` при 1400 (сделано старым
  редактором, харнесс `mkfix`); из t11 удалены 5 утверждений про migrate, остальные — только пути.
- **Ловушка оболочки**: `pkill -f 'serve.py 8791'` убивает сам вызывающий shell (его командная строка содержит тот
  же текст). Сервер в скриптах убивать по PID.
- **Вырезки** пока не перенесены (`process_cutout` отвечает ApiError) — шаг 2.

## Шаг 2 (01.10.2026): вырезки на Python, оракул «байт в байт»

- Проверка детерминированности перед портом: `bash process.sh` ×2 и ×2 с `MAGICK_THREAD_LIMIT=1` — sha1 вырезок
  и фонов одинаковы во всех четырёх прогонах (IM 7.1.2-25 Q16-HDRI, 12 потоков). Лимит потоков в `run()` всё же
  оставлен: страховка от другого числа ядер у друзей, вырезки маленькие.
- `cutout_args()` — чистая функция, аргументы 1:1 из `process.sh cutout()`: скобки `(`/`)` — отдельные аргументы
  (так их видел magick после word-splitting в bash), `_noise/_map` возвращают списки, арифметика целочисленная
  (`A=(M*5+1)//2`, `pad=M+A+2`, `fw=width-2*pad`). Параметры темы (бумага, тон, кайма, дизеринг, цвета) — из
  `images.cutout`, константы шума/морфологии зашиты.
- `tests/test_images.py`: эталон = копия старого `process.sh` в `tests/ref/` + записанная версия IM (иначе skip).
  Всё сравнивается по sha1, **кроме курсоров**: эталон не отключал chunk'и с датой в PNG, у него самого sha гуляет;
  порт их отключает (файл не меняется от сборки к сборке — push не заливает лишнее), тест сравнивает пиксели
  (`magick compare -metric AE` = 0).

## Шаг 3 (01.10.2026): манифест темы и панель «тема»

- **Одна форма манифеста** (`_afisha/theme.json`): `kinds` — поведение вида (match = CSS-селектор для `el.matches`,
  флаги с дефолтами из `defaults`), `blocks` — кнопки палитры (id, kind, html, width, pick). Разделены, потому что
  у одного вида scrawl три кнопки (цитата/заметка/служебное), а у field две (поле, окно-терминал).
- **Порядок kinds = приоритет `kind()`**: атрибутные match (`[data-nav]`) раньше классовых, pic раньше field
  (у фото оба класса). Сервер при валидации проверяет, что html каждой кнопки резолвится в свой kind — иначе
  ошибка, не предупреждение (`theme.resolve_kind` с мини-селекторами `tag.class[attr]`); клиент повторяет ту же
  проверку через `matches` и пишет предупреждения в консоль и модалку темы.
- **Правило 1 — только `overlap:true`** (field). Флаг `text` из первого черновика отброшен: он попал бы на scrawl,
  ticker, подвал, и `overlaps()` начал бы запрещать то, что по шапке style.css накладываться может.
- **theme.css** генерируется сервером: `@font-face`, `:root` (цвета, vars, `--bg-image`, стеки шрифтов,
  color-scheme), выключенные экранные слои. `style.css` темы — только структура; структурные `rgba(11,20,16,…)`
  заменены на `color-mix(in srgb, var(--night) N%, transparent)`, иначе светлая тема получала тёмные градиенты.
  Оракул «до/после»: `magick compare -metric AE -fuzz 2%` = 0 (без fuzz ≈3% пикселей отличаются на 1 единицу —
  округление color-mix в градиентах).
- **Панель «тема»** правит только theme.css: цвета с живым предпросмотром (inline-переменные на `<html>` iframe,
  снимаются при закрытии модалки), шрифты (первое семейство стека, локальные из faces + системный список), фон,
  экранные слои, число цветов дизеринга и «как есть» на тип. После `POST /api/theme` перечитывается один `<link>`
  (`theme.css?v=`), DOM, история и выделение не теряются; пересобранные картинки — сброс `src`.
- **Legacy**: сайт без theme.json (старый entropic division до adopt) работает с манифестом шаблона forest,
  фон — regex по style.css, кнопка «тема» скрыта.
- Тест независимости: `tests/fixture-paper` (2 вида, 3 цвета, без слоёв/эффектов/шрифтов) + t20-theme (20
  утверждений). Ловушка харнессов: `const`-функции theme.js (`isTextField`) не свойства окна — только `W.eval`.
- Загрузка iframe теперь ждёт `/api/state` до `injectStyle` (манифест нужен раньше стилей правки).

## Шаг 4 (01.10.2026): i18n ru/en

- `editor/i18n.js` грузится первым: словари `I18N.ru/en` (~230 ключей), `t(key, vars)` с подстановкой `{name}`,
  `L({ru,en})` для подписей манифеста (переехала из theme.js), `applyLang()` по `data-i18n` (textContent),
  `data-i18n-html` (innerHTML — подсказки с `<code>`/`<br>`), `data-i18n-title`, `data-i18n-placeholder`;
  `setLang()` перерисовывает палитру, панель свойств и подписи листа. Переключатель — `<select id="lang">` в баре,
  хранится в `localStorage ed-lang`; **по умолчанию `ru`, не язык браузера** (headless Firefox отдаёт en-US, старые
  харнессы ждут русские статусы).
- Статусы через `sayk(key, err, vars)` пишут `statusEl.dataset.key` — тесты проверяют ключ, а не текст.
- Заготовка новой страницы теперь из манифеста (`new_page_block`), а не зашитый `section.field`.
- Что не переводится: тексты внутри html-шаблонов блоков (заготовки темы) и сообщения сервера (`{error, hint}` —
  русские; заголовок `X-Lang` пока не используется, серверная локализация отложена).
